# Public website (`apps/web`, Next.js 16 App Router)

Server-rendered, bilingual (fa default at `/`, en at `/en`), signed in through Keycloak (Auth.js). It never talks to the
database: all data comes from the Go API, server side. Check your work with `pnpm --filter @alanfelez/web typecheck` and the
page in the browser pane at http://localhost:3000 (after `task web:reload`), in **fa and en, at phone width (375 px) and desktop**.

## Where things are
| Path | What |
|---|---|
| `src/app/[locale]/<page>/page.tsx` | One folder per page. `actions.ts` next to it = its server actions (`"use server"`) |
| `src/lib/*.ts` | Server-only data access per area (`prices.ts`, `content.ts`, `gold.ts`, `account.ts`), SEO (`seo.ts`, `site.ts`), nav (`nav.ts`) |
| `src/lib/api.ts` | `api` (anonymous, cacheable) and `callerApi()` (with the user's token when signed in) |
| `src/components/` | Shared UI: `prices/*` (ticker, cards, table, charts), `content/*`, `gold/*`, `Locked`, `Header`, `Footer`, `MobileNav` |
| `messages/fa.json`, `messages/en.json` | **All UI text**, by namespace (`prices`, `auctions`, `lock`, …). Add every key to both files |
| `src/proxy.ts` | Next "proxy" (middleware): session refresh, `/en` redirect while English is off, locale routing, CSP nonce |
| `src/lib/security-headers.ts` | CSP and security headers. A new external origin (a form target, an image host) must be added here |
| `src/app/sitemap.ts`, `robots.ts` | SEO. **A new public page goes into `PAGES` in sitemap.ts** |
| `../../packages/ui` | Shared formatters (`@alanfelez/ui/format`: `formatToman`, `formatDate`, `formatNumber`, `formatBp`, `formatTons`…), fonts, tokens |
| `../../packages/api-client` | Generated typed client + `Schemas[...]` types. Regenerated by `task generate`; never hand-write API types |

## The shape of a page (copy `src/app/[locale]/auctions/page.tsx`)
```tsx
export const dynamic = "force-dynamic";                     // pages that depend on the user or on live data
type Params = { params: Promise<{ locale: Locale }> };

export async function generateMetadata({ params }: Params): Promise<Metadata> {
  const { locale } = await params;
  const t = await getTranslations({ locale, namespace: "thing" });
  return seo(locale, "/thing", { title: t("title"), description: t("subtitle") });   // canonical, hreflang, OG, robots
}

export default async function ThingPage({ params }: Params) {
  const { locale } = await params;
  setRequestLocale(locale);
  const t = await getTranslations("thing");
  const data = await getThing(locale);                      // from src/lib/<area>.ts, never fetch() inline
  if (!data) return <p className="… text-down">{(await getTranslations())("error.apiDown")}</p>;
  …
}
```
- **Data functions** live in `src/lib/<area>.ts` with `import "server-only"`. Public, same-for-everyone data: `api` +
  `next: { revalidate: N }`. Anything that depends on the caller: `callerApi()` + `cache: "no-store"` (never cache personal data).
- **Locked features:** the API decides and sends `locked` / `requiredPlan` or a `FEATURE_LOCKED` problem, and no data.
  Show `<Locked plan={…}>` from `src/components/Locked.tsx`. Never fetch the data and hide it in the browser.
- **Forms** post to server actions (`actions.ts`, pattern: `src/app/[locale]/contact/actions.ts`) that return a small status
  object (`"sent" | "invalid" | "limited" | "failed"`); the client component shows the translated message. Pass on
  `X-Forwarded-For` for anything the API rate-limits per IP.
- **Navigation:** add a new top-level page to `src/lib/nav.ts` (header, phone menu), `sitemap.ts`, and the footer if it belongs there.
  Links use `Link` from `@/i18n/navigation` (keeps the locale).

## Rules that are easy to break
- **Server components by default.** `"use client"` only for interactivity, and a `"use client"` file **exports components only**:
  constants or helpers used by server code go in a plain module (`lib/nav.ts`, `components/gold/calc-form.ts`). Otherwise the
  server gets a client reference instead of the value (this crashed the calculator page once).
- **No hard-coded text.** Every visible string is a message key in **both** `fa.json` and `en.json`, or CMS content from the API.
  Persian copy from the client is copied verbatim.
- **Numbers, money, dates** only through `@alanfelez/ui/format` (Persian digits, Jalali in fa, Toman from Rial).
- **RTL/LTR:** logical Tailwind classes only (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`, `text-start`, `border-s`). Never `left`/`right`/`ml`/`mr`/`pl`/`pr`.
- **Mobile first:** design at 360 px, then `sm:`/`md:`/`lg:`. Tables become cards below `md` (see `PriceTable`).
- **Prices always show the source and the "last updated" time.** Never words like «قیمت قطعی» or «تضمین سود».
- **Inline `<script>`** needs the CSP nonce (read `x-nonce` from headers; see `components/JsonLd.tsx`). No external scripts, fonts or CDNs.
- Accessibility: real `<button>`/`<a>`, labels on inputs, visible focus, `alt` on images.

- Font **Vazirmatn** (self-hosted, 300–900). Cards: `rounded-card border border-border bg-surface shadow-soft`. Prices bold and larger.
- Animations: ticker scroll (`ticker-scroll`), chart line draw-in (`draw`), live dot (`pulse`).
- Tier badges: رایگان gray, نقره‌ای blue-gray, طلایی gold. Icons: a duotone set, not emoji (SCOPE §11).
- Figma prototype (older than the screenshots, F1): https://ratio-donkey-94517275.figma.site/. Newest screens: `docs/design/screenshots/summary-draft/`.
  Prototype calculator (reference only; final logic SCOPE §8): net = weight × (1−impurity%), value = net × price × (1−deductions%) − shipping.
