# ADR-0009: Bilingual: Persian (default, RTL) and English

- **Status:** Accepted
- **Date:** 2026-09-28

## Context
The client requires Persian and English (answer #24).

## Decision
Web: **next-intl** with `fa` at `/` and `en` at `/en`, `hreflang`, localized metadata, and `dir` per locale. Admin: Refine i18n provider (fa/en UI). Content: localized columns (`title_fa`, `title_en`, …), and the API returns the requested locale (`Accept-Language` / `?lang=`). **Logical CSS only**. Jalali dates and Persian digits for `fa`, Gregorian and Latin for `en`. Playwright screenshots in both locales.

## Consequences
English is content work only, not a rewrite. Every component must be checked in both directions.

## Alternatives considered
Persian-only now and retrofitting later (costly).
